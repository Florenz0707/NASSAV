# 任务详情 Demo

已选定“列表与详情”布局：列表用于快速识别资源和比较任务状态，右侧明细用于查看封面、下载指标、刮削阶段及失败原因。原三种布局保留于历史分支 `demo/unified-task-details`（`9128461`），本轮只细化选定方案。

从前端目录运行：

```bash
pnpm demo:tasks
```

访问 `/downloads?demo=tasks`。旧的 `variant` 参数不再切换布局。

列表显示资源封面缩略图、名称、AVID、任务类型、状态和进度；选中行突出显示，明细展示大图、任务编号与最近更新时间。下载显示百分比、速度和大小；新增/刷新刮削显示实际阶段名称，不伪造下载进度。未获取元数据的任务以 AVID 标识，并明确显示名称和封面待获取。当前封面是本地 SVG 示例插画，用于评估布局，不是真实资源封面；深浅主题复用设计 token。

支持全部/下载/刮削筛选、状态筛选、选中明细与内存中的阶段演示；窄屏明细排列到列表下方，表格在自身容器内横向滚动。所有任务均为模拟，不提交、取消或重试真实任务，不保存演示状态。

Demo 组件仅在开发环境加载，生产构建不包含此页面。正式下载入口及名称保持既有行为；开发 Demo 中页面与导航名称为“任务详情”。本轮确定展示结构，尚未接入正式任务 API。

真实接入需复用 downloadQueue 和现有 visibleScrapeJobs，标题复用 resourceTitle，封面使用资源已有的 thumbnail_url/cover_url 或现有封面接口。统一展示层状态，同时保留两种任务的阶段差异。当前刮削列表来自本浏览器追踪的任务，不代表服务器完整历史；翻译已排队不代表翻译完成。正式历史、跨设备可见性和可取消范围需在接入阶段明确。
