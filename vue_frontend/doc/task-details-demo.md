# 任务详情与调试预览

正式 `/downloads` 页面和导航名称为“任务详情”，采用“列表与详情”布局。URL 保持兼容，旧 `demo=tasks` 参数不再切换模拟页。

`DownloadsView` 装配 downloadQueue 的当前下载队列、resource store 的 visibleScrapeJobs 和元数据，TaskDetailsPanel 只管理筛选及选中展示。标题使用 resourceTitle 及用户偏好，优先已有元数据；封面使用缩略图 / 封面 URL 或现有封面接口，加载失败显示占位。下载显示真实百分比、速度和大小；刮削显示阶段及失败信息，缺失信息不伪造。刮削成功保留独立含义；列表显示整合后的统一阶段，明细展示该次任务的翻译子任务状态，排队中继续轮询，后端原始刮削成功仍表示资源已保存；页面整体状态包含翻译，排队或运行时显示执行中、完成时显示已完成、失败时显示失败。资源名称优先使用快照中的原始/来源/译后标题及用户偏好，下载补查已有元数据。

列表任务列只显示 AVID，全部任务下增加彩色 scrape / download 类型 badge 列；其余列显示状态、阶段、不再跟踪和结束任务，右侧显示大图与任务明细，小屏明细排列到列表下方。可筛选全部 / 下载 / 刮削及状态；当前任务消失或不符合筛选时，选择回退到第一项。已有资源提供重点色圆角矩形“查看资源”链接，本轮不增加重试或取消接口。列表操作列提供单条、勾选批量及当前筛选列表已结束任务的“不再跟踪”，二次确认后仅移除本浏览器跟踪，不取消后台任务或删除资源。刮削移除记录与轮询，下载按任务 ID 隐藏（最多保留 500 个隐藏 ID）；迟到响应不能恢复已移除任务。失败阶段直接显示失败。

下载接口是当前队列，不含完整终态历史；任务完成后从队列移除。本浏览器追踪的刮削任务也不代表服务器完整历史，统计仅基于可见数据。下载页进入时读取一次队列，WebSocket 失败后使用轮询补偿，离开页面使旧读取失效；队列读取失败保留旧快照并明确提示。

活动时间线放入任务明细，每个状态右侧右对齐显示记录时间；新增刮削任务记录阶段进入时间，翻译结束时间使用 Celery 的完成时间。旧任务缺失记录时显示未记录，不用当前时间伪造历史。下载仅显示队列中实际保留的创建、开始及更新时间，不代表完整历史。已结束包括完成和失败，翻译仍运行的刮削任务不被批量清理。结束任务按钮与批量入口仅为禁用示意，不实现取消。详情不再显示“不再跟踪此任务”。

## DEBUG_MODE

将 `src/views/DownloadsView.vue` 中 `DEBUG_MODE` 设置为 `true`，运行 `pnpm dev` 并访问 `/downloads`：使用独立样例展示下载、刮削、等待、完成和失败，以及 SVG 示例封面。“演示下一阶段 / 演示重试”仅修改本页模拟状态。页面不读取真实下载队列，不将样例写入 store，不混入真实任务。应用全局连接与原有后台任务跟踪仍遵循应用生命周期。

默认值为 `false`；调试完成后恢复该值。旧 Demo 保存在历史分支 `demo/task-list-resource-details`（`1cdcdb4`），正式展示与调试复用同一组件，避免两套布局分叉。

任务操作列使用 eye-off SVG 表示不再跟踪，close SVG 表示结束任务，并保留可访问名称和悬停提示；批量入口使用图标加文本。复选框未选中时使用主题副文本色的加粗边框，在深浅主题中保持清晰轮廓；选中和半选继续使用主强调色。

任务状态筛选最小宽度为 8rem，切换短标签不收缩。批量操作按钮不显示选择数，计数统一放在全选复选框右侧，表头与行保持对齐。空列表使用 EmptyState 的 compact 模式（不添加内部留白），在首屏扣除应用主容器上下留白后的剩余区域居中；无 action 插槽时不保留空操作间距。阶段列仅显示统一阶段，不再附加独立翻译状态行，详情和整体任务状态继续保留翻译结果。
