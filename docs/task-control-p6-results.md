# P6：持久任务列表与前端控制

分支 `feat/task-control-ui`，基线 `7d0b186`。提交见 Git 的 `[Feat] Add persistent task controls to task details`。

## 已实现

新增分页持久列表、逐项鉴权的批量操作；既有接口契约快照保持，新增路径独立检查。taskJobs 是新任务前端快照所有者，稳定 job_id、版本拒绝乱序、会话失效、WS 提示和轮询兜底。历史任务继续兼容但不开放控制。资源保存触发资源列表刷新，翻译仍受父任务整体状态管理。

任务页接入单条和批量暂停、恢复、终止，终止先确认；等待实际停止确认，不乐观标成已暂停/终止。清理状态单独展示，失败重试。已结束包含 cancelled，普通批量隐藏保留清理未完成项。本地隐藏按登录用户记忆稳定 ID，不取消后台任务。列表显示加载范围，批量最多每组 100 项。DEBUG 开关支持内存模拟操作，定时器卸载清理。
