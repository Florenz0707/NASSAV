# 个人观看历史与稍后观看

观看历史记录实际播放，稍后观看是手动管理的个人队列；两者独立于收藏、已观看、备注和播放进度。共享资源事实、媒体文件和推荐历史保持原有所有者，不开放多用户登录权限。

## 状态与写入

UserWatchHistory唯一(user,resource)，列表按last_watched_at降序。同一资源无论本地/源站或不同播放页面均只有一条，再次实际观看更新到队首。用户或正式资源删除级联删除历史，重新添加资源不恢复旧历史；这与按AVID保留的播放进度不同。没有周期TTL，不根据既有进度或手动watched推测旧历史。

viewing.record_view先取得短用户写入fence，再验证当前登录绑定的播放会话、ready/有效期及generation，网络和媒体读取不进入事务。每次play后首次playing是一个观看事件；暂停恢复产生更高sequence，缓冲重复playing不产生新事件。同会话更低/相同sequence重试不改变排序，避免已经处理过的旧请求在新观看之后再次置顶。刷新同会话不重置计数，旧代次拒绝。播放器销毁解除监听，迟到结果不改新页面状态。浏览器事件是客户端观察结果，并非后端能够证明用户观看的时长；不做完成度或推荐权重推断。

记录不依赖播放进度writer：只读播放也记录历史，claim/save不自动记录；未播放、准备失败或只打开页面均不新增。失败显示简短提示并允许重试，播放器继续使用；不阻断播放或擅自夺取保存权。

UserResourceState保存watch_later及首次加入时间，与收藏/备注共享version。部分更新只改提交字段；重复加入不改变时间，移除后再加入置顶。播放、完成、历史记录均不自动移除稍后观看，也不自动标记已观看。列表读当前用户的状态，GET不创建记录，失效资源不保留悬空队列。

## 接口与界面

个人列表由request.user绑定，分页读取，不接受外部user_id；只投影资源摘要与队列时间，不返回源站播放URL、媒体路径或其他用户的身份。响应private,no-store；详情ETag仍绑定个人快照。前端资源库菜单提供“观看历史与稍后观看”，详情支持加入/移除；列表使用公共按钮/封面/空状态/加载/错误/分页，播放另开标签，回来后刷新列表。

公开字段与错误见[接口](interface.md#个人观看列表)，新增表/回退见[数据库](database.md#0036观看历史与稍后观看)。上线前备份并统一消费者，执行0036；回退丢弃本轮新数据，保留旧个人标记、设置与进度。
