# 异步资源任务 P2 前端反馈验证

日期：2026-09-26。分支：`feat/scrape-progress-ui`，从 P1 分支创建。P2 仅切换前端资源添加、刷新、批量添加/刷新；批量删除和下载行为仍使用原接口。

## 实现

- 资源 API 改用任务提交接口。HTTP 202 只登记任务并提示“已排队”；成功/失败提示由签名状态查询确认终态后发出。
- 资源 store 按 `task_id` 保存状态、查询令牌和版本。提交后立即查询快照；WebSocket 事件仅触发已知任务查询；5 秒轮询负责断线补齐。浏览器重新加载、切回前台和 WebSocket 重连都会补查未结束任务。状态按版本和时间戳合并，终态不回退。
- 应用级资源任务区展示排队、实际阶段与最终结果。添加页批量结果逐项区分已排队、已完成、已存在和失败；详情、资源列表、演员和类别页面在终态后更新数据。推荐页只在添加真正成功后标记资源已入库。
- 本阶段保留现有 WebSocket 下载事件。资源事件使用单独的 `scrape_job_update` 类型；全局广播只含任务 ID 与阶段等有限字段，完整快照要求提交时返回的签名令牌。公开多用户部署仍需访问控制与订阅隔离。
