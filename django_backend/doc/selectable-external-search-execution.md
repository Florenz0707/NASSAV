# 演员、类别搜索源可选：执行与验收记录

日期：2026-10-01。工作目录 `/tmp/nassav-agent-worktree`，分支 `feat/selectable-external-search`。

## P0：真实路径验证，通过

- 现状：Jable 已有演员/类别适配器；MissAV 为占位；前端两页固定 Jable。
- 初轮 `/cn`、`/cn/actresses`、`/cn/genres` 未取得有效 HTML。当前配置使用的浏览器服务日志存在代理出口 IP 发现超时；后续根首页和英文目录成功，不能认定出口检测为唯一原因。
- [MissAV 首页](https://missav.ai/) 当前可能跳转动态 `dmN` 路径。只读实测 `/en/actresses/{名称}` 与 `/en/genres/{名称}` 去掉动态前缀后仍有效；两种列表各验证两页，每页 12 张卡片且第二页首番号不同。
- `/en/search/{日文演员名}` 和类别 `?sort=views` 为业务有效页面。排序链接提供 `views`、`saved`、`released_at`；卡片没有播放量/收藏量数值，因此使用源站排序，MissAV 仅提供降序选择。

## P1：后端适配，通过

MissAV 新增列表 URL、解析及业务校验；通过现有 `PageFetchService` 使用各源配置的直连/浏览器策略及会话复用开关。搜索入口先刷新共享 Cookie/UA 快照。校验同站、非挑战、标题和卡片结构，并拒绝跳到其他路径的页面；动态 `dmN` 前缀允许变化。普通版、字幕版和解禁版按番号去重，保留发现的详情链接。

复用已有演员/类别源映射；MissAV slug 保留大小写，可由源 URL 提取和解码。没有映射时按名称关键词搜索，界面明确说明此模式不能保证演员/类别精确归属。无需新增表或迁移。

## P2：源能力与失败语义，通过

新增 `/source/search-capabilities`，仅返回已启用且已实现的源及排序能力，保留原下载源接口形状。缺省源仍为 Jable；未知源/不支持的排序为 400，禁用/未实现为 503，抓取失败为 502。用户提示与诊断 reason 分开。失败及不完整结果不缓存；有效空结果为 200。

成功缓存按实体、源、域名、代理路线和排序隔离。分页沿用配置限制页数采集后的本地分页，显示总数是采集窗口内条数；不是全站总量。映射调整后可使用强制刷新。

## P3：前端选择，通过自动验证

演员和类别详情页复用 `CustomSelect`，以能力接口生成可选项。记住会话内选择，按源隔离页面/会话缓存，切换源重置分页，旧请求返回不会覆盖新源、新实体或新分页。保留对应排序能力及明确失败提示，结果添加任务使用对应源。

收尾发现旧 30 秒 Axios 超时和 120 秒代理超时不足以覆盖多页浏览器请求；演员/类别详情搜索单独使用 450 秒客户端预算和 600 秒 Nginx 读取预算。一般 API 仍为原预算。请求配置回归及临时容器 `nginx -t` 均通过；若修改后台采集窗口或浏览器预算，需要同步评估这两个超时。

前端 Node 测试 24 项通过；`pnpm run lint:fix`、`pnpm run build` 通过。源选择、禁用回退和异步覆盖保护由自动测试验证；没有进行人工浏览器界面验收。
