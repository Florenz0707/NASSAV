# 中文与异步外部搜索执行记录

## 范围

在 `/tmp/nassav-agent-worktree` 完成 P0–P4，按功能分支提交并合并 idle。执行前删除 main、dev、idle 以外的本地分支；远程分支不涉及。

## P0 基线

旧搜索 URL 固定 `/en/`；封面代理仅允许 Jable 域名。现场中文类别页面跳转 `dm2093/cn`，演员页面跳转 `dm288/cn`，均返回 12 张卡片、中文标题及 fourhoi.com 图片，分别约 21.39 和 61.60 秒。中文 URL 回归在旧实现上失败；真实 CDN 图片带中文 Referer 和源代理返回 HTTP 200、37010 字节。

## P1–P3

MissAV 搜索改用 `/cn/`，保留动态 dmN 兼容，检查最终域名与路径，并支持中文空结果。服务端缓存升级 cn-v4，页面缓存同步更新。

封面代理按 source 区分；MissAV 使用实测 CDN 白名单、源代理、中文 Referer及下载限制，卡片失败显示占位图。Jable 保持现有代理入口。

默认源接入服务端配置、序列化器、Pinia 和设置页，页面临时切源不改变默认配置。源不可用时回退并提示。范围沿用实例共享设置，无数据库迁移。

## P4

新增任务提交及签名状态接口，复用现有 Celery/Redis 和 JobStore。所有后台抓取通过现有 scrape 队列限制并发，与资源刮削共享队列，因此繁忙时搜索会排队。保持原同步详情接口兼容。

前端显示等待与执行状态，每 1.5 秒轮询。切源、翻页、离开页面中止旧请求和定时器；终态失败可通过页面重新搜索重试。异步化缩短提交请求耗时，上游抓取耗时仍然存在。

## 验证

现场验证使用隔离 SQLite、独立 Redis、真实 Celery worker 和 Byparr；抓取窗口为 1 页，生产默认抓取窗口未改。五组现场验收全部成功：MissAV 类别、演员、关键词各 12 条；Jable 类别、演员各 20 条，图片均 HTTP 200。提交请求 0.005–0.085 秒，后台及图片完成 25.66–65.86 秒。详见 [验收数据](chinese-async-external-search-evidence.jsonl)。

最终后端全量测试：457 passed、13 skipped，81.98 秒；前端 28 项测试通过，lint、构建及 `pre-commit run -a` 全部通过。

收尾时一轮全量测试的推荐反馈用例出现随机排序失败：原用例未固定推荐新颖度的随机种子却断言固定顺序。仅为该测试固定 random_seed=42，单项及全量复测通过，推荐业务实现未改变。此次未进行人工浏览器 UI 验收，图片验收为真实后端代理请求及图片响应验证；前端通过构建和交互逻辑测试。

## 部署与限制

需要更新 API、scrape worker 和前端。设置为实例共享；未引入独立账号偏好。MissAV CDN 更换域名后需重新验证并更新白名单。后台搜索与资源刮削共享串行队列；如后续排队明显，可另设搜索 worker，但需协调站点浏览器并发。
