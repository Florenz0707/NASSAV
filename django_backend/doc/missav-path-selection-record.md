# MissAV 详情路径选择：现场对照与持久化评估

日期：2026-09-30。范围：MissAV 详情页路径。现场探针在正式 API 容器中读取有效配置，使用同一 Byparr 与代理路线；不读取或修改 Cookie、Redis、任务；生产库抽样仅只读获取 3 个资源番号，不修改资源数据。使用 [只读探针](../scripts/probe_missav_paths.py) 对同一番号交错比较路径，逐项脱敏记录见 [JSONL 证据](missav-path-selection-evidence.jsonl)。有效性必须通过现有 `PageFetchService.validate_result` 的同站点、非挑战检查，以及 MissAV 的番号标题和视频 UUID 检查；Byparr 提供方响应本身不算业务成功。

## 样本与结果

首页发现的 50 个不同番号中，首轮取前 20 个，发现链接均位于 `/en/…`；补充取序号 31–40 的 10 个，其中 5 个发现链接带动态 `/dmN/…` 前缀。另覆盖生产库现有的 3 个 `source=MissAV` 番号；旧样本重新在线验证，不沿用过去的有效性结论。样本均来自同一时段及出口，不能代表未来站点、其他代理或全部番号。首页 471 个链接中未发现 `chinese-subtitle` 链接；额外检查的一个有效普通详情页没有同番号字幕链接，但这些观察不能证明站点没有字幕详情页。

失败的字幕页均返回 `page_mismatch`，并非仅靠 HTTP 状态推断无效。11 个包含现行三条生产候选的配对样本中，现行“字幕 CN → 字幕根 → 普通 CN”三次 Byparr 调用的**请求耗时之和**中位数为 49.805 秒；如果普通 CN 首次即被接纳，单次请求中位数为 10.372 秒，可避免的两次请求耗时之和中位数为 38.579 秒（范围 33.114–46.680 秒）。这些数值不含代码在失败后的 1 秒等待、直连兜底和 API/worker 调度，也不是跨两时段的放行结果。两种普通路径在本次小样本中都有效，不能据中位数的细微差异断言哪条导航更快；`/cn/{avid}` 的优势是无需先发现当前 `/en/…` 链接，且已有生产回退路径。

## 路径选择结论

普通 `/cn/{avid}` 应作为无已验证路径时的默认首选；保留字幕路径作为候选，最终仍逐页校验番号和 UUID。若产品仍要求“只要中文字幕版存在就优先下载”，需要先有可信的字幕版发现信号，不能仅凭本次 0/11 样本推断它永远不存在，也不应将所有字幕候选永久删除。只有本站有字幕版本的有效正例，才能测出该版本与普通版本的内容差异及优先级代价。若普通 CN 失效，`/en/{avid}` 或搜索/列表发现的真实路径值得作为后续回退实验；动态 `/dmN/en/…` 前缀不能从番号稳定构造，必须由实际链接发现。当前单窗口结果支持针对候选顺序的有限修正，尚不足以证明缓存、会话复用或正式端到端 P95 已达标。

## “有效权重”能否持久化、动态化

可以，但**路径本身与路径族的成功率应分开存**。优先实现按 `(source, domain, avid)` 记住最近一次经过业务校验的相对路径，记录 `verified_at` 与最近失败时间；API 与 worker 可通过 PostgreSQL 共享。重复请求先试该路径，若业务失配则废弃并按候选顺序重新查找。写入前只接受当前站点、已验证番号和 UUID 的页面；不存 Cookie、HTML、UA 或带查询参数的 URL。设置短有效期，并按域名变化自动失效。Redis 可作热缓存，但默认缓存 TTL 与持久性均不足以独立承担“持久化”。

全局路径族权重只在收集足够的**实际尝试**后再启用。可按 `(domain, path_kind, 时间窗口)` 聚合“有效 / 业务失配”与耗时，用平滑先验和时间衰减计算排序；403、挑战、连接失败及浏览器不可用只能记录为基础设施失败，不能当作路径不存在。只观察已排序的首条成功路径会造成选择偏差，字幕路径将永远没有新正例；需要低频、受预算约束的探索或可信列表/搜索发现信号。字幕偏好是业务约束，不应被纯成功率覆盖。权重变更需要最小样本量、排名变化上限、域名隔离、回滚和两时段有效率/耗时对照。当前只有一窗口 33 个普通路径和 11 个字幕路径的现场样本，且未找到有效字幕正例；直接建立自学习数据库表和在线更新机制会增加迁移、写放大与错误反馈风险，先记录设计，等待正例与重复率证据再实施。

## 复测建议

1. 对本次普通 CN 首选方案，在另一个独立时段及新增番号上复测；报告业务有效率、平均浏览器调用数和完整 `get_html()` P50/P95。
2. 用当前列表或搜索结果专门寻找确实存在的中文字幕详情正例；比较普通与字幕版的 UUID、标题及实际媒体信息，明确产品优先级。
3. 若多个请求反复抓同一番号，再实现按番号记住已验证相对路径；若站点整体路径规则频繁改变，再考虑带受控探索的路径族权重。
