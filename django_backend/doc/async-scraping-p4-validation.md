# P4 Compose 验证记录

日期：2026-09-26。分支：`chore/full-stack-compose`，从 P3 分支创建。验证使用独立 Compose 项目 `nassav-p4-check`、`/tmp/nassav-p4-check` 数据目录和宿主机 `127.0.0.1:9781`，未挂载既有后端数据库或资源目录。

| 检查         | 结果                                                                                                                                                                                                                                          |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 镜像和迁移   | 后端、前端镜像构建成功；`migrate` 以退出码 0 完成，API/worker 后启动。下载器为固定 x64 0.5.1 版本，镜像内 ICU、ffmpeg 和下载器版本命令可执行。                                                                                                |
| 网关与内网   | 前端 `/` 和 `/nassav/api/source/list` 均为 HTTP 200；仅 `127.0.0.1:9781` 发布端口。API 容器访问 Byparr `/docs` 为 200，Redis 健康检查通过。                                                                                                   |
| WebSocket    | 网关返回 101，收到 `queue_status`。三路并发握手分别为 25、41、42 ms，均收到初始事件。API 容器单独重建后网关仍返回 200；初次发现静态解析会保留旧容器 IP 并产生 502，已改用 Docker DNS 动态解析。                                               |
| 队列         | `scrape`、`download`、`default` worker 各监听对应队列，并发与预取为 1。可选 Beat 单实例启动并在持久化目录生成 `schedule`。                                                                                                                    |
| 真实资源添加 | `JUR-466` Jable 任务提交返回 202。直连先收到 403，浏览器回退后任务状态为 `succeeded`，数据库有资源与 M3U8；任务从提交到终态约 60 秒。隔离环境无可用 Ollama，翻译状态为 `failed`，需在目标环境配置容器可达翻译服务。                           |
| 实际下载     | 在隔离网络提供 2 秒自制 HLS，API 对 `P4-TEST` 返回 202，下载 worker 生成 9,489 字节 MP4，数据库 `file_exists=True` 且记录正确文件大小。首次运行发现镜像缺少 ffmpeg；补齐后通过。                                                              |
| 重启与路径   | `down` 再 `up` 后资源行、MP4、签名任务终态快照均保留。视频路径接口返回映射后的宿主机文件路径。Redis AOF、SQLite 与 WAL/SHM、资源、Beat 状态均放在各自持久化目录；`sync_backups` 从默认 worker 可读取 Beat 状态并写入独立的 `backup_sync` 卷。 |

本次没有测真实外站视频下载、长任务的下载进度间隔、代理出口、批量源样本成功率或生产数据回滚；这些属于 P5 联调与切换验收。Compose 样本的默认翻译器须连接目标机上的 Ollama，不能把资源添加成功解释为翻译也成功。Byparr 内存观察值为启动后约 409 MiB，非峰值。目标部署仍需按[计划](async-scraping-compose-plan.md)记录队列等待、外站耗时、下载吞吐、SQLite 锁错误和回滚结果。

后端全量测试：260 passed、13 skipped；定向视频路径测试：4 passed；前端 `pnpm run build`、`pnpm run lint:fix` 通过。根目录 `pre-commit run -a` 通过。最终代码的定向测试与全量 pre-commit 复核均通过。
